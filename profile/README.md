# 👋 Welcome to KMC SDOC

We’re a team building practical tools and documentation that make day-to-day work simpler, clearer, and more reliable.

## How to contribute
We welcome issues, ideas, and pull requests.

1. Open an issue to discuss improvements or bugs
2. Fork and create a focused branch
3. Submit a PR with a clear summary of what changed

## Community values

- Be constructive
- Keep it simple and helpful
